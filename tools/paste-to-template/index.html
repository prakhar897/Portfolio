How to

  • Use {{name}} to create an input named name.
  • Use {{date}}, {{time}}, {{datetime}}, or {{timestamp}} for automatic values.
  • Use eval(2 + 3) to calculate a value inside a command.
  • Click a completed command to copy it. It turns green when copied.
  • Fill every text box in a template to copy the completed command automatically.

Keyboard shortcuts

  • Press Cmd/Ctrl + a template number to focus its first text box. For template 12, press Cmd/Ctrl + 1, then Cmd/Ctrl + 2.

Templates are stored locally in your browser using Local Storage. They will be lost if browser storage is cleared.

What Paste to Template is good for

A fast text template builder for reusable messages, commands, emails, invoices, and snippets. Fill variables once, generate the final text instantly, and copy it to your clipboard automatically.

Paste to Template helps you turn repeated writing into reusable text templates. It is useful for support replies, sales outreach, meeting notes, invoice text, status updates, password reset messages, shell commands, and any workflow where the same sentence or command needs a few changing values.

Templates run locally in your browser and can include custom variables, automatic date and time values, simple calculations, and keyboard shortcuts for quickly jumping to a template. Once every required field is filled, the completed text is copied automatically so it is ready to paste into email, chat, documents, terminals, or internal tools.
